🎮 Number Guessing Game

A fun and interactive Number Guessing Game developed using Java and Spring Boot with a simple and attractive web interface.

🚀 Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- Maven

✨ Features

- Interactive user interface
- Number guessing functionality
- Backend integration using Spring Boot
- User-friendly design

📂 Project Structure

- "src/main/java" – Java backend source code
- "src/main/resources/static" – Frontend files
- "pom.xml" – Maven dependencies and configuration

▶️ How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open the terminal in the project folder.
4. Run:

./mvnw spring-boot:run

On Windows PowerShell, use:

.\mvnw.cmd spring-boot:run

5. Open your browser and visit:

"http://localhost:8080"
